# PANADERO Repository Structure

This repository contains one active local-laptop application. The old duplicate `apps/` prototype and role ZIP archives have been removed to prevent editing or launching the wrong files.

```text
PANADERO/
├── PANADERO-COSTUMER/
│   └── PANADERO-COSTUMER/PANADERO-COSTUMER/
│       ├── *.html
│       └── assets/{css,images,js}
├── PANADERO-STAFF/
│   └── PANADERO-STAFF/
│       ├── staff-*.html
│       └── assets/{css,images,js}
├── PANADERO-ADMIN/
│   └── Panadero-Admin/admin/
│       ├── admin.html
│       └── assets/{css,images,js}
├── database/
│   └── panadero.sql             Canonical complete schema
├── docs/
│   ├── PANADERO-LOCAL-ERD-UPDATED.md/.png
│   ├── PANADERO-LOCAL-SYSTEM-MASTER-BOOK.md/.pdf
│   ├── PANADERO-SYSTEM-GUIDE.md
│   ├── PANADERO-PROFESSOR-QA-EN-TL.md/.pdf
│   └── PANADERO-CCS110-FINAL-ANSWERS-EDITABLE.docx
├── login.html                   Root role login/redirect page
├── server.js                    Express API and static-file server
├── PANADERO-ONE-CLICK.bat       Windows setup and launcher
├── LOCAL-SETUP.md                Local setup guide
├── .env.example                 Safe environment template
└── package.json                 Node.js scripts and dependencies
```

## Which files should be edited?

- Backend/API behavior: `server.js`
- Database structure: `database/panadero.sql` and, when needed, the migration section in `server.js`
- Customer API services: `PANADERO-COSTUMER/.../assets/js/*-service.js`
- Staff API data layer: `PANADERO-STAFF/.../assets/js/staff-data.js`
- Admin API synchronization: `PANADERO-ADMIN/.../assets/js/admin.js`
- Visual design: the active portal HTML/CSS/images under the three role folders
- Local setup: `PANADERO-ONE-CLICK.bat`, `.env.example`, and `LOCAL-SETUP.md`

## Do not commit

- `.env` — contains database credentials.
- `node_modules/` — generated by `npm install`.
- Temporary ZIP exports — create them outside the Git repository for handoff.
